Solar mppt algorithm is definded by the solid state silicon cell semi conductor.  

A wind turbine is not a semiconductor, it is a wind power convertor.  A solar mppt algorithm is not the most effective way of yielding all the power from the turbines conversion and will also tend to cycle the machine as the algorithm hunts.


All commercial wind turbines do no use solar mppt algorithms.  They use lookup tables and or 3rd, 4th, 5th order polynomial terms to control the inverter base on either the inputvoltage or the frequency of the turbine."
